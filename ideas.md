# ideas

## 2026-11-19

Para que rimas ayude más a escribir, de más a menos útil:

- **Guardar palabras** (~30 min): tocar una palabra la apunta en una lista que se queda en el navegador, para no perder las rimas buenas mientras se salta de una a otra.
- **Modo letra** (una tarde): escribir la canción entera; busca rimas para la última palabra del verso donde está el cursor.
- **Copiar con un toque** (~10 min): ahora tocar una palabra la busca; un toque largo podría copiarla.
